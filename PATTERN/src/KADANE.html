What is Kadane's Algorithm?

Kadane's Algorithm is a dynamic programming technique used to find the maximum sum of a contiguous subarray in an array of integers (which may contain negative numbers). It was proposed by Jay Kadane in 1984 and runs in O(n) time with O(1) space.

Core Implementation
int maxSubarraySum(int[] nums) { int currMax = nums[0]; int globalMax = nums[0]; for (int i = 1; i < nums.length; i++) { currMax = Math.max(nums[i], currMax + nums[i]); globalMax = Math.max(globalMax, currMax); } return globalMax; }
Decision at each step: extend or start fresh
Track two values: current max (ending here) and global max (overall)
Core Idea

At each position i, decide:

1️⃣ Start fresh — begin a new subarray at nums[i]

2️⃣ Extend — add nums[i] to the current subarray

currMax = max(nums[i], currMax + nums[i])

The 4 Core Variations

Kadane's Algorithm can be adapted to solve many different problems.

Classic Kadane Max Sum
Find the maximum sum of a contiguous subarray.
currMax = Math.max(nums[i], currMax + nums[i]); globalMax = Math.max(globalMax, currMax);
Use for: Maximum Subarray (LeetCode 53)
Product Variation Max Product
Track both max and min (negative × negative = positive).
currMax = max(nums[i], currMax*nums[i], currMin*nums[i]); currMin = min(nums[i], currMax*nums[i], currMin*nums[i]);
Use for: Maximum Product Subarray (LeetCode 152)
Circular Variation Wrap Around
Max subarray that can wrap around the array boundaries.
circularMax = totalSum - minSubarraySum; return Math.max(normalMax, circularMax);
Use for: Maximum Sum Circular Subarray (LeetCode 918)
With Deletion Forward + Backward
Max subarray sum after deleting at most one element.
forward[i] = max sum ending at i backward[i] = max sum starting at i max = max(forward[i-1] + backward[i+1])
Use for: Maximum Subarray Sum with One Deletion (LeetCode 1186)

How to Recognize Kadane's Pattern

These clues in problem statements should immediately make you think of Kadane's Algorithm.

"Maximum subarray sum"→ Classic Kadane
"Maximum product subarray"→ Product Variation
"Circular array"→ Circular Variation
"Delete one element" → Forward + Backward Kadane
"Largest contiguous sum" → Standard Kadane
"Maximum score" → Often Kadane DP

Common Mistakes

These mistakes are responsible for most wrong answers during interviews.

❌ Initializing current sum with 0

If the array contains only negative numbers, answer becomes incorrect.

Correct: Initialize using first element.
❌ Resetting sum before updating answer

Update global answer first, then continue.

Correct: globalMax = Math.max(globalMax,currentMax)
❌ Forgetting all-negative case

Returning zero for [-5,-2,-1] is wrong.

Correct: Never initialize answer with 0.
❌ Confusing Prefix Sum and Kadane

Prefix Sum computes range sums. Kadane finds best contiguous sum.

Remember: Prefix = Query Kadane = Optimization
