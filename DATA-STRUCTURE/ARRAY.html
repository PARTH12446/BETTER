What is an Array?

An Array is a linear data structure that stores a collection of elements at contiguous memory locations. Each element can be accessed directly using its index (0-based in most languages).

Declaration
// Java int[] arr = new int[5]; int[] arr = {1, 2, 3, 4, 5}; ArrayList<Integer> list = new ArrayList<>(); // Python arr = [1, 2, 3, 4, 5]
O(1) random access Cache-friendly Contiguous memory
Complexity Cheat Sheet
Access by indexO(1)
Search (unsorted)O(n)
Search (sorted)O(log n)
Insert at endO(1) amortized
Insert at beginningO(n)

The 6 Core Patterns of Arrays

Master these six patterns and you can solve 90% of array problems.

Two Pointers Opposite / Fast-Slow / Sliding
Use two pointers to traverse the array from different positions.
// Opposite ends int L = 0, R = n - 1; while (L < R) { // process arr[L] and arr[R] if (condition) L++; else R--; }
Use for: Finding pairs, reversing, partitioning, palindrome
Prefix Sum Cumulative
Precompute cumulative sums for O(1) range queries.
int[] prefix = new int[n]; prefix[0] = arr[0]; for (int i = 1; i < n; i++) { prefix[i] = prefix[i-1] + arr[i]; } // sum[L..R] = prefix[R] - prefix[L-1]
Use for: Subarray sums, range queries, cumulative calculations
Kadane's Algorithm Max Subarray
Track current max and global max in a single pass.
int currMax = arr[0], globalMax = arr[0]; for (int i = 1; i < n; i++) { currMax = Math.max(arr[i], currMax + arr[i]); globalMax = Math.max(globalMax, currMax); } return globalMax;
Use for: Maximum subarray sum, maximum product subarray
Cyclic Sort 1 to n
Place each element at its correct index (arr[i] = i+1).
for (int i = 0; i < n; i++) { while (arr[i] != i + 1 && arr[i] != arr[arr[i] - 1]) { swap(arr, i, arr[i] - 1); } }
Use for: Missing numbers, duplicates, arrays with 1 to n
Dutch National Flag 3-Way Partition
Sort arrays with three values (0, 1, 2) using three pointers.
int low = 0, mid = 0, high = n - 1; while (mid <= high) { switch (arr[mid]) { case 0: swap(arr, low++, mid++); break; case 1: mid++; break; case 2: swap(arr, mid, high--); break; } }
Use for: Sorting 0s, 1s, 2s; three-way partitioning
Rotation & Reversal In-place
Reverse entire array, then reverse parts to rotate.
// Rotate right by k reverse(arr, 0, n - 1); reverse(arr, 0, k - 1); reverse(arr, k, n - 1); // Reverse helper void reverse(arr, L, R) { while (L < R) swap(arr, L++, R--); }
Use for: Array rotation, reversing, next permutation

How to Recognize Array Patterns

These clues in problem statements should immediately make you think of a specific pattern.

"Find pair/triplet with sum"→ Two Pointers (opposite ends)
"Subarray sum equals K"→ Prefix Sum + HashMap
"Maximum subarray sum"→ Kadane's Algorithm
"Numbers 1 to n, find missing/duplicate"→ Cyclic Sort
"Sort 0s, 1s, 2s"→ Dutch National Flag
"Rotate array by k"→ Reversal technique
"Longest/shortest subarray with condition"→ Sliding Window
"Buy and sell stock"→ Single pass tracking min/max
"Merge intervals"→ Sort + merge
"Next permutation"→ Find pivot + reverse

Common Mistakes

If your array solution is wrong, it's almost always one of these things.

Index out of bounds

Accessing arr[i] when i is < 0 or ≥ n.

Fix: Check i >= 0 && i < n before accessing.
Off-by-one errors

Using L < R vs L <= R, or forgetting the last element.

Fix: Be explicit about inclusive vs exclusive ranges.
Modifying array while iterating

Changing the array while iterating over it can skip elements.

Fix: Use a copy or track changes separately.
Not handling empty array

Solutions fail when n == 0.

Fix: Always handle the empty array edge case first.
Integer overflow in sum

Sum of large numbers can exceed int max value.

Fix: Use long for sums in prefix and Kadane.
Assuming array is sorted

Many solutions assume sorted input when it's not.

Fix: Sort first if the pattern requires it.
