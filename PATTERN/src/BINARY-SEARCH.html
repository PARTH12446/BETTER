Definition

Binary Search is a divide-and-conquer algorithm that repeatedly divides a sorted array or search space in half to find a target value or optimal solution.

04

How to Apply It — Templates

Classic template
int left = 0, right = n - 1; while (left <= right) { int mid = left + (right - left) / 2; if (arr[mid] == target) return mid; if (arr[mid] < target) left = mid + 1; else right = mid - 1; } return -1;
Answer / search space
int left = minPossible, right = maxPossible; while (left < right) { int mid = left + (right - left) / 2; if (can(mid)) right = mid; else left = mid + 1; } return left;
Tip: Use mid = left + (right - left) / 2 to avoid overflow.

07

Common Mistakes

If your binary search is wrong, it's almost always one of these four things — in roughly this order of likelihood.

Off‑by‑one in loop condition

Using left < right when you need left <= right (or vice versa) misses the last element or causes an infinite loop.

Fix: be explicit about inclusive vs exclusive bounds. Stick to one style and test the edge case (n=0, n=1).
Forgetting to adjust mid when moving left

Writing left = mid instead of left = mid + 1 can cause an infinite loop when left and right are adjacent.

Fix: always set left = mid + 1 when moving left, and right = mid or mid - 1 consistently.
Wrong monotonic predicate

The predicate (e.g., can(mid)) must be monotonic. If it's not, binary search is invalid — you'll get wrong answers without realizing it.

Fix: test the predicate for small ranges manually before writing the search.
Ignoring overflow in mid calculation

In languages with fixed‑size integers, (left + right) / 2 can overflow if left and right are large.

Fix: use left + (right - left) / 2 in all languages, even if you think overflow won't happen.
