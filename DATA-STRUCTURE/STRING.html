What is a String?

A String is a sequence of characters. In most programming languages, strings are immutable (cannot be changed after creation). Operations like concatenation, substring, and character access are fundamental.

Declaration
// Java String str = "Hello World"; char c = str.charAt(0); // 'H' String sub = str.substring(0, 5); // "Hello" // Python str = "Hello World" c = str[0] # 'H' sub = str[:5] # "Hello"
Immutable (Java, Python) Mutable with StringBuilder Unicode support
Complexity Cheat Sheet
Access by indexO(1)
LengthO(1)
ConcatenationO(n)
SubstringO(n)
Search (contains)O(n)

The 6 Core Patterns of Strings

Master these six patterns and you can solve 90% of string problems.

Two Pointers Palindrome
Use two pointers from opposite ends to compare characters.
int L = 0, R = s.length() - 1; while (L < R) { if (s.charAt(L) != s.charAt(R)) return false; L++; R--; } return true;
Use for: Palindrome checking, reversing, comparing from ends
Sliding Window Substrings
Expand R, shrink L when constraint breaks.
Map<Character, Integer> lastSeen = new HashMap<>(); int L = 0, maxLen = 0; for (int R = 0; R < n; R++) { char c = s.charAt(R); if (lastSeen.containsKey(c) && lastSeen.get(c) >= L) L = lastSeen.get(c) + 1; lastSeen.put(c, R); maxLen = Math.max(maxLen, R - L + 1); }
Use for: Longest substring without repeating, minimum window
Frequency Counting Anagram
Use int[26] for lowercase letters or HashMap for all characters.
int[] freq = new int[26]; for (char c : s1.toCharArray()) freq[c - 'a']++; for (char c : s2.toCharArray()) freq[c - 'a']--; for (int count : freq) if (count != 0) return false; return true;
Use for: Anagrams, character frequency, duplicates
StringBuilder Building Strings
Use StringBuilder for multiple concatenations to avoid O(n²) time.
StringBuilder sb = new StringBuilder(); for (int i = 0; i < n; i++) { sb.append(chars[i]); } return sb.toString();
Use for: Multiple concatenations, building strings efficiently
Stack Parentheses
Use stack to match opening and closing parentheses.
Stack<Character> stack = new Stack<>(); for (char c : s.toCharArray()) { if (c == '(' || c == '[' || c == '{') stack.push(c); else { if (stack.isEmpty() || !isMatch(stack.pop(), c)) return false; } } return stack.isEmpty();
Use for: Valid parentheses, expression evaluation, decoding
DP & Hashing Matching
Dynamic programming for string matching or hash maps for mapping.
// Isomorphic Strings - HashMap mapping Map<Character, Character> map1 = new HashMap<>(); Map<Character, Character> map2 = new HashMap<>(); for (int i = 0; i < n; i++) { if (map1.containsKey(s1.charAt(i)) && map1.get(s1.charAt(i)) != s2.charAt(i)) return false; map1.put(s1.charAt(i), s2.charAt(i)); }
Use for: String matching, isomorphic strings, word break, DP

How to Recognize String Patterns

These clues in problem statements should immediately make you think of a specific pattern.

"Palindrome"→ Two Pointers (opposite ends)
"Anagram"→ Frequency counting (HashMap/array)
"Longest substring without repeating"→ Sliding Window + HashMap
"Substring with at most K distinct"→ Sliding Window
"Valid parentheses"→ Stack
"String matching"→ KMP / Rabin-Karp
"Reverse string"→ Two Pointers or StringBuilder
"Check if strings are isomorphic"→ HashMap mapping
"Group anagrams"→ HashMap with sorted string as key
"Word break"→ DP / Trie

Common Mistakes

If your string solution is wrong, it's almost always one of these things.

Forgetting immutability

Using `str +=` in a loop creates many intermediate strings (O(n²) time).

Fix: Use StringBuilder for multiple concatenations.
Index out of bounds

Accessing char at index i when i >= str.length() or i < 0.

Fix: Check i >= 0 && i < n before accessing.
Not handling empty string

Solutions fail when `str.isEmpty()` or `str.length() == 0`.

Fix: Always handle the empty string edge case first.
Case sensitivity

String comparisons are case-sensitive by default.

Fix: Use toLowerCase() or toUpperCase() when needed.
Ignoring non-alphanumeric in palindrome

Forgetting to skip non-alphanumeric characters in palindrome problems.

Fix: Skip non-alphanumeric characters using Character.isLetterOrDigit().
Inefficient substring in loop

Substring creates a new string each time, O(n) cost.

Fix: Use indices or StringBuilder instead of creating substrings.
