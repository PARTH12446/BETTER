What is a HashMap?

A HashMap is a data structure that stores data in key-value pairs. It uses a hashing technique to compute the index of the bucket where the value will be stored.

Java
import java.util.HashMap; HashMap<KeyType, ValueType> map = new HashMap<>();
O(1) avg get/put 1 null key Many null values
Key Characteristics
  • O(1) average time for get/put
  • Stores key-value pairs
  • Not thread-safe (use ConcurrentHashMap)
  • No guaranteed order (use LinkedHashMap)

Understanding the internals helps you write better code and debug performance issues.

Hash → Index — Hash code is modulo'd with capacity to find bucket index

}

2
Index calculation — index = (n - 1) & hash

Where Can HashMap Be Applied?

HashMaps are extremely powerful in these scenarios — recognize when to reach for them.

Fast lookups — O(1) average time
Count frequencies — Word count, character frequency
Check existence — Has this element been seen before?
Unique mappings — ID → value, URL → shortened URL
Caching/memoization — Store intermediate results in DP
Group by key — Group anagrams, group by property
When to Use

You need O(1) lookups

You see "count", "most", "duplicate", "frequency"

You need to map one type to another (String → Integer)

You need to remember previously seen values

You need grouping or partitioning data

Example Use Cases with Code

Real patterns you'll see over and over again in coding problems.

Count Frequency
Map<Character, Integer> freq = new HashMap<>(); for (char c : str.toCharArray()) { freq.put(c, freq.getOrDefault(c, 0) + 1); }
Pattern: Character → Frequency
Two Sum
Map<Integer, Integer> map = new HashMap<>(); for (int i = 0; i < nums.length; i++) { int complement = target - nums[i]; if (map.containsKey(complement)) { return new int[]{map.get(complement), i}; } map.put(nums[i], i); }
Pattern: Value → Index
Group Anagrams
Map<String, List<String>> map = new HashMap<>(); for (String word : words) { char[] chars = word.toCharArray(); Arrays.sort(chars); String key = new String(chars); map.computeIfAbsent(key, k -> new ArrayList<>()).add(word); }
Pattern: Sorted String → List of Anagrams
Subarray Sum Equals K
Map<Integer, Integer> prefixSum = new HashMap<>(); prefixSum.put(0, 1); int sum = 0, count = 0; for (int num : nums) { sum += num; if (prefixSum.containsKey(sum - k)) { count += prefixSum.get(sum - k); } prefixSum.put(sum, prefixSum.getOrDefault(sum, 0) + 1); }
Pattern: Prefix Sum → Frequency

07

Best Practices

Write cleaner, more efficient HashMap code with these tips.

Use getOrDefault()
freq.put(c, freq.getOrDefault(c, 0) + 1);
Avoids null checks and simplifies counting.
Use computeIfAbsent()
map.computeIfAbsent(key, k -> new ArrayList<>()).add(value);
Clean way to handle List initialization.
Use immutable keys

String, Integer are safe. For custom objects, override hashCode() and equals().

Initialize with capacity
Map<String, Integer> map = new HashMap<>(initialCapacity);
Reduces rehashing overhead for large datasets.
08

Common Mistakes

Avoid these pitfalls when working with HashMap.

Mutable objects as keys

Using mutable objects as keys can change their hash code after insertion, making them unretrievable.

Fix: Use immutable keys (String, Integer) or override hashCode/equals.
Not handling null values

HashMap allows null values, but map.get(key) returns null for both missing keys and null values.

Fix: Use containsKey() to check existence before get().
Modifying while iterating

Modifying a HashMap while iterating over it throws ConcurrentModificationException.

Fix: Use Iterator or copy the map before modification.
Not considering collision overhead

Poor hash codes or many collisions degrade performance to O(n) or O(log n).

Fix: Use proper initial capacity and good hash functions.
